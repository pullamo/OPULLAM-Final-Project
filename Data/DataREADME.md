# Overview
The data folder stores all the sources, files, and data dictionary used in this project.

## Data Dictionary
| Field Name | Data Type | Description |
| ...... | ...... | ...... |
| Title | String [python] | Title of the movie |
| Release Date | Datetime64(ns) | Date the movie was released |
| Budget | int(32) | Budget of the movie in USD | 
| Domestic Gross | int(32) | Domestic Revenue earned in USD | 
| Worldwide Gross | int(32) | Total revenue worldwide in USD |
